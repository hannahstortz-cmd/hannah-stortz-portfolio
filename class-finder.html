Class Finder

View the Live Page

Project Overview

This project focused on updating Cedarville University’s Admissions Class Finder, which helps prospective students find classes to attend during their campus visit. The goal was to modernize the look and feel and create a design that better matched Admissions marketing emails and visit materials.

Design Challenge

The challenge was to make the Class Finder feel more fun and youthful for a high school audience while keeping class information easy to find. The design also needed to support different visit days, including CU Friday and All Access, and use color to break up information and create a clearer hierarchy.

Approach

I began with an Admissions meeting to discuss the audience, visual direction, and potential updates. Using those notes, I sketched a layout with a banner area for specific visit days, rounded buttons, and class cards with a drop shadow.

Within each card, I organized the subject, class name, time, professor, and location to make the information easier to scan. I also included subject, time, and day filters, along with options to save and view favorite classes.

Outcome

The updated Class Finder brought a refreshed visual direction to a tool used by prospective students during campus visits. The design focused on helping visitors browse class information and keep track of the classes they wanted to attend while creating a more consistent experience with Admissions visit materials.
